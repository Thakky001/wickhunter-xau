# 📝 แผนอัพเกรดในอนาคต: ระบบ Dynamic Risk (2% Compounding)

ไฟล์นี้คือแผนปฏิบัติการ (Blueprint) ที่เราเตรียมไว้สำหรับการอัพเกรดบอทเทรดจริง `smcEngine.js` ในอนาคต เมื่อคุณพร้อมที่จะเปลี่ยนจาก "Lot คงที่" ไปเป็น "ระบบคำนวณ Lot อัตโนมัติ" เพื่อสร้างพลังดอกเบี้ยทบต้น (Compounding)

## 🎯 เป้าหมายของการอัพเกรด
- **เปลี่ยน:** จากเดิมที่ตั้งค่า `FIXED_LOT_SIZE = 0.02` เป็นค่าคงที่
- **เป็น:** ระบบที่ดึง "ยอดเงินคงเหลือในพอร์ตจริง (Balance)" มาคำนวณหา Lot Size ที่พอดีกับระยะ SL ของแต่ละออเดอร์ โดยกำหนดความเสี่ยงตายตัวที่ **2% ของพอร์ต**
- **ผลลัพธ์ที่คาดหวัง:** กำไรโตแบบทบต้นก้าวกระโดดเมื่อพอร์ตใหญ่ขึ้น และปกป้องพอร์ตให้รอดพ้นจากการขาดทุนติดๆ กัน (Max Drawdown ถูกบีบให้น้อยลงในเชิงเปอร์เซ็นต์)

---

## 🛠️ รายละเอียดทางเทคนิค (สำหรับบอท smcEngine.js)

### 1. สมการคำนวณ Lot Size อัตโนมัติ
สูตรคณิตศาสตร์ที่เราจะใส่เข้าไปใน `smcEngine.js` เมื่อเปิดออเดอร์:
```javascript
const RISK_PERCENT = 0.02; // เสี่ยง 2% ของพอร์ต

// 1. หาว่าออเดอร์นี้ยอมเสียเงินได้กี่เหรียญ
const maxRiskAmount = currentBalance * RISK_PERCENT;

// 2. หาระยะ SL (ระยะห่างระหว่างจุดเข้า กับจุดตัดขาดทุน)
const slDistance = Math.abs(entryPrice - slPrice);

// 3. เนื่องจากเรายิง 2 ไม้ (Dual TP) แต่ละไม้จึงรับความเสี่ยงครึ่งหนึ่ง
const riskPerPosition = maxRiskAmount / 2;

// 4. คำนวณมูลค่าเงินต่อจุด (Dollars per point)
const dollarsPerPoint = riskPerPosition / slDistance;

// 5. แปลงเป็น Lot Size (สำหรับทองคำ 1 Lot = $100 ต่อระยะ 1 จุด)
let calculatedLot = dollarsPerPoint / 100;

// 6. ปัดเศษ Lot ให้รองรับขั้นต่ำของโบรคเกอร์ (เช่น 0.01)
calculatedLot = Math.max(0.01, Math.round(calculatedLot * 100) / 100);
```

### 2. สิ่งที่ต้องแก้ไขในระบบเชื่อมต่อ Deriv API
ในการยิงออเดอร์จริง เราจะต้องส่งค่าตัวแปร `calculatedLot` (หรือที่ Deriv เรียกว่า `volume`) ไปพร้อมกับคำสั่งเทรด 
- เราจะต้องปรับฟังก์ชัน `executeTrade()` ให้รับพารามิเตอร์ `lotSize` แบบ Dynamic แทนที่จะไปดึงค่าคอนฟิก `FIXED_LOT_SIZE` จากบรรทัดบนสุด
- **สิ่งสำคัญ:** ต้องเขียนดักจับ API Error ในกรณีที่คำนวณ Lot ออกมาใหญ่เกินลิมิตของโบรคเกอร์ (Max Lot) เพื่อป้องกันระบบล่ม

### 3. การแสดงผลบน Dashboard (Log & UI)
- ใน Console Log ของ Render ต้องอัพเดทให้ปริ้นบอกด้วยว่า *"คำนวณ Lot ได้เท่าไหร่ และระยะ SL กี่จุด"* เพื่อให้ตรวจสอบย้อนหลังได้ง่าย
- *(อนาคต)* ถ้ามีหน้าเว็บ Dashboard สามารถทำเส้นกราฟแสดงการเติบโตของ Lot Size ควบคู่กับ Balance ได้เลย
